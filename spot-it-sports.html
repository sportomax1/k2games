Game guide

How to play

Each round shows two circular cards. Exactly one symbol is identical on both. It might be a team logo, sports emoji, or real athlete headshot. Tap either copy to score.

  • ALL 6: Mix every league. Each card includes as many different leagues as its chosen logo count allows.
  • CORE 4: NFL, NBA, MLB and NHL only.
  • Single league: Pick NFL, NBA, MLB, NHL, college football (CFB) or Division I men’s college basketball (CBB). CFB includes ESPN-mapped FBS and FCS teams; CBB uses the 2025–26 Division I field.
  • Content: Select team logos, sports emojis, player faces, or a mixture. Mixed rounds include all available symbol types on each card.
  • College fallback: Player-only mode uses authentic pro athlete headshots; CFB and CBB use team logos where college player faces are not available. Sports emoji mode has a shared, all-sports emoji pool regardless of league.
  • Difficulty: 4, 6, or 8 symbols per card. More symbols make matching harder.
  • Timer: Score as many matches as you can in 30–120 seconds. Wrong taps count as misses and cost 1 second.
  • Fair timer: The countdown pauses briefly while the next pair of images is prepared, and you can manually pause the game.

High scores are saved in this browser separately for each league, symbol mode, difficulty and timer combination. ESPN logo and athlete images need internet access; text placeholders appear if images fail.
